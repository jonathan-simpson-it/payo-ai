Fonts

- UI / headings / body: Inter (variable, via next/font). Weights used: 400 regular, 500 medium, 600 semibold, 700 bold. Headings use tight tracking (−0.01 to −0.03em); body is sentence case.
- Mono / labels / numbers: Geist Mono (via next/font). Used for kickers (UPPERCASE, tracked +0.1em), table figures, and code-like chips. Always tabular numerals for financial figures.
  Deck rules of thumb
- Dark slides: #0D0F12 background, #E9EDF2 text, #C9500A for CTAs/emphasis only, cards #14171B with 8–14% white borders. Don't flood slides with orange.
- Buttons: solid #C9500A with #FFFFFF text.
- Keep one accent (orange) + neutrals; status colors only for genuine states.
